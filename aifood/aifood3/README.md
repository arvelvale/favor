# Flavor Fusion 邮件功能使用说明

本项目包含两种发送邮件的方式：
1. 使用Gmail API发送邮件（test_gmail_api.py）
2. 使用QQ邮箱SMTP服务直接发送邮件（simple_qq_mail.py）

## 使用QQ邮箱发送邮件（推荐）

由于Gmail API在某些网络环境下可能存在连接问题，我们推荐使用QQ邮箱的SMTP服务直接发送邮件。

### 前提准备

1. 拥有一个QQ邮箱账号
2. 获取QQ邮箱的SMTP授权码（注意：这不是QQ邮箱的登录密码）

### 获取QQ邮箱授权码的步骤

1. 登录您的QQ邮箱(https://mail.qq.com)
2. 点击页面顶部的【设置】
3. 选择【账户】选项卡
4. 找到【POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务】部分
5. 开启【POP3/SMTP服务】
6. 点击【生成授权码】按钮
7. 根据提示完成验证步骤，获取授权码
8. 保存此授权码，它将用于发送邮件

### 配置脚本

打开 `simple_qq_mail.py` 文件，修改以下两行为您的信息：

```python
sender_email = 'your_qq_email@qq.com'  # 替换为您的QQ邮箱
sender_password = ''  # 替换为您刚获取的授权码
```

### 运行脚本

```bash
python simple_qq_mail.py
```

运行后，按照提示输入收件人邮箱地址，系统会自动发送一封测试邮件。

### 常见问题

1. **邮件发送失败，提示"认证失败"**：
   - 请确认您使用的是授权码而不是QQ邮箱密码
   - 检查授权码是否正确输入（没有多余空格）
   - 授权码可能已过期，请重新生成

2. **邮件发送失败，提示"连接超时"**：
   - 请检查您的网络连接
   - 确认防火墙没有阻止SMTP连接

## 使用Gmail API发送邮件（需要特定网络环境）

如果您希望使用Gmail API发送邮件，请参考 `test_gmail_api.py` 文件。这种方式需要进行OAuth授权，且在某些网络环境下可能遇到连接问题。

由于网络环境的原因，我们不推荐使用此方式，除非您确定网络环境支持稳定连接到Google服务器。
